# 보고서 AI 초안과 RAG 연결 설계

## 서버가 검색할 자료

| 근거 | 저장 위치 | 검색 조건 |
|---|---|---|
| 작성 기준 | 같은 폴더의 rag-reference.md | R1 집계, R2 근거, R3 초안 형식 |
| 지표·추이·로그 출처별 수 | 보고서 스냅샷 | 선택한 KST 기간과 지표 |
| 사건·대응 기록 | SOC 저장소 | 담당자가 선택한 사건 ID와 기간 내 조치 |
| 개별 로그 근거 | 정규화 이벤트 저장소 | 선택 사건에 연결되고 담당자가 고른 이벤트 ID |

기간과 식별자로 조회하는 방식부터 적용한다. 실데이터는 런타임에 검색한다. 로그 원문이나 실데이터를 Git 참고 파일에 복사하지 않는다.

## 초안 API

- 내부 초안 요청은 기간 유형, 기준 날짜, 선택 지표·사건·이벤트 ID를 받는다. 쓰기 권한과 CSRF를 검사하고, 서버가 기간·연관 관계를 검증한 뒤 조회한다.
- 기준 문서와 구조화 근거를 나눠 전달한다. 근거에 M1, I1, L1 같은 ID를 붙이고 계정과 IP는 별칭으로 가린다. 공급자에 원문, 토큰, 쿠키, 자유 입력 로그를 전달하지 않는다.
- 공급자 설정은 서버 환경 변수로 관리한다. 설정과 전송이 허용된 자료 범위를 확정한 뒤 연동한다. 오류가 나도 기존 초안은 보존한다.
- 응답은 summary, assessment, followup 및 항목별 evidence_refs로 받는다. 길이와 참조 ID를 검증하고 미리보기로 표시한다.
- 담당자가 검토한 집계·근거 스냅샷을 확정본에 고정한다. 동시 수정은 버전으로 검사한다.
- 확정본 인쇄/PDF는 보고서 화면에서 제공한다. 발송은 수신자 확인, 별도 승인, 성공·실패 감사 이력을 갖춘 후 연결한다.

현재 문서는 공급자 연결 전 계약이다. 초안 API, 근거 선택 UI, 발송은 후속 구현 범위다.
