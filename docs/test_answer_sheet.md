# 시험 정답표 (1~10일 차 검증 기준)

| 시험 ID | 대상 일차 | 시나리오 / 입력 | 기대 결과 (정답) |
|---|---|---|---|
| `T01` | 1일 차 | 시험 단말 → 게이트웨이 → 임시 HTTP 서버 정상 요청 | HTTP 200 응답, 게이트웨이 `fw_allow` 로그 1건 |
| `T02` | 1일 차 | 시험 단말 차단 적용 후 시험 단말 & 대조 단말 요청 | 시험 단말 접속 실패(`fw_deny`), 대조 단말 정상 접속(`fw_allow`) |
| `T03` | 1일 차 | 시험 단말 차단 해제 후 재요청 | 시험 단말 정상 접속 복구(`fw_allow`) |
| `T04` | 2일 차 | `gateway.jsonl` 허용/차단 로그 수집 후 수집기 재시작 | 관제 DB `raw_logs`, `normalized_events`에 각 1건씩만 저장 (중복 0건) |
| `T05` | 2일 차 | 개행(`\n`) 없는 미완성 줄 기록 후 수집기 실행 → 이후 개행 추가 | 미완성 줄은 보류, 개행 추가 후 1회만 저장 및 `collector_offsets` 갱신 |
| `T06` | 3일 차 | 동일 신뢰(`client_ip_trusted=true`) `username + client_ip` 로그인 실패 `N-1`건 | 경보 0건 |
| `T07` | 3일 차 | 동일 신뢰 `username + client_ip` 로그인 실패 `N`건 (시간창 내) | 첫 경보 1건 발생 |
| `T08` | 4일 차 | 실제 ERP 로그인 실패 요청 1건 | Caddy·ERP 로그가 동일 `request_id`로 연결, 사건 화면에서 `raw_id` 조회 가능 |
| `T09` | 5일 차 | 관제 앱에서 사람 승인 후 차단 → 해제 | 시험 단말만 차단, 해제 후 복구, 승인 이력·적용/해제 결과 표시 |
| `T10` | 6일 차 | 동일 승인 ID 재시도 / 합성(`synthetic`)·재생(`replay`) 로그 입력 | 만료 시각 연장 없음, 합성·재생 로그에서는 방화벽 조치 요청 0건 |
| `T11` | 7일 차 | 만료된 승인 / 공유 IP 두 사용자 / UTC 자정 경계 | 만료 승인으로 차단 재발생 없음, 공유 IP만으로 사건 병합 안 됨, UTC 기준 정상 계산 |
| `T12` | 8일 차 | ERP DB 초기화 실행 | 관제 DB의 기존 `raw_id` 및 사건·경보·승인 이력 100% 보존 |
