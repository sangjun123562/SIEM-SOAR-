# SIEM · SOAR PPT 제작 지침 패키지 v2

목표: 캡스톤 기술 발표의 내용은 보존하면서, 정보 위계·기술 그래픽·제품 화면·검증 시각화를 전문적인 발표 디자인으로 개선한다. 최종 PPT를 생성한 패키지는 아니다.

```text
presentation/
├── README.md
├── DESIGN.md              # 개정 디자인 시스템 · 품질 게이트
├── ART_DIRECTION.md       # 전체 연출 · 현재 문제 분석 · 레퍼런스 적용
├── SLIDE_LAYOUTS.md       # 대표 4장 와이어프레임 · 15장 상세 배치
├── CONTENT.md             # 기존 내용 지침과 10개 보완 항목 유지
├── references/
│   ├── design/            # 사용자 선정 레퍼런스 + REFERENCE_NOTES.md
│   ├── anti-patterns/     # 사용자 제공 개선 전 시안 3장
│   └── source/            # 기존 PPT와 학습 교재
├── assets/                # 실제 ERP·관제 캡처 및 증거
└── output/                # 제작 산출물만 저장
```

## 작업 순서

1. 마음에 드는 디자인 자료를 `references/design/`에 저장하고 `REFERENCE_NOTES.md`에 어떤 부분이 마음에 드는지 기록한다. 주 레퍼런스 1개와 슬라이드 유형별 예시 4~8장 정도 권장.
2. Codex에서 PPT 제작 스킬을 선택하고 아래 첫 요청을 전달한다. 실제 프로젝트 저장소는 읽기 전용으로 사용한다.
3. 레퍼런스를 분석하여 디자인 방향을 확정한다. 대표 4장만 먼저 제작·렌더링·검수한다.
4. 대표 디자인을 사용자 승인한 후 전체 15장과 필요한 부록을 제작한다.

## Codex 첫 요청

```text
presentation/README.md, DESIGN.md, ART_DIRECTION.md, SLIDE_LAYOUTS.md, CONTENT.md를 읽어라.
references/design/의 내가 선택한 레퍼런스를 분석하라. references/anti-patterns/는 개선 전 시안이므로 따라 만들지 마라. 기존 PPT의 내용과 대본은 활용하되 디자인은 전면 개선한다.
단순한 미니멀리즘, 동일한 사각형 나열, 반복 헤더, 평면적인 숫자와 표로 끝내지 마라. 슬라이드마다 시각 중심, 정보 위계, 의미 있는 기술 그래픽을 설계하고 실제 화면은 제품 쇼케이스처럼 다뤄라.
먼저 디자인 방향과 구체적인 참조 원리를 기록하고, 표지·전체 시스템 아키텍처·관제 대시보드·검증 결과(본편 01,04,10,13)만 제작해라. 전체 PPT는 아직 생성하지 마라. 실제 PPT 제작 스킬을 사용하여 편집 가능한 pilot.pptx를 만들어 PNG로 렌더링하고 원본 시안과 비교하라. 레퍼런스가 없으면 먼저 미확정임을 알려라.
실제 프로젝트 코드 및 증거를 읽기 전용으로 확인하고 확인한 SHA와 근거를 output/evidence.md에 기록해라. 최신 WAF, 팀 기여도, 시험 결과를 추정하지 마라. 같은 사건의 증거인지 확인되지 않으면 하나의 사건으로 표시하지 마라. 필요한 실제 이미지와 근거는 output/missing-assets.md에 적어라. Toolkit은 본편에서 제외한다.
DESIGN.md의 품질 게이트를 통과하도록 수정한 대표 4장, PNG, 모아보기, 디자인 결정 및 검수 기록을 output/에 제출해라. 내 승인 이후에만 전체 PPT를 제작한다.
```

## 승인 이후 요청

```text
승인한 시안의 디자인 언어와 실제 레퍼런스의 적용 원리를 유지하되, 15장을 동일한 레이아웃으로 반복하지 마라. CONTENT.md의 내용·시간과 SLIDE_LAYOUTS.md의 장별 목적을 지켜 전체 PPTX를 제작해라. 부록은 필요한 질문 대비 자료로 구성하고, 발표자 노트에 자연스러운 한국어 대본과 시간·근거를 포함해라. 전체 슬라이드를 렌더링하고 가독성·그래픽·기술 사실을 검수하여 output/에 최종본과 검수 기록을 저장해라. 미확인 내용과 최신 시험 미실행 여부를 밝혀라.
```

기존 10분/본편 15장 계획과 10개 보완 항목은 유지했다. 참고 디자인은 사용자 선택 전이며 컬러와 폰트는 임시 기준이다. 이 지침 개정 과정에서는 최신 프로젝트 코드/시험을 재검증하지 않았고 기존 프로젝트 원본이나 PPT를 수정하지 않았다. 기존 폴더가 있다면 파일을 비교하여 지침 5개와 새 레퍼런스 폴더를 반영하되, 작업 중인 output 및 사용자의 레퍼런스는 덮어쓰지 않는다.
