## 가져오지 않은 것
- `api/*.js`(Supabase·Node.js 서버): Flask(`erp/app.py`)로 새로 작성
- `.env`, 키·토큰, 실제 데이터, `.git`, 캐시, `data.json`, 서비스 워커·매니페스트·아이콘, 기기 승인(`/api/device`) 기능

원본 저장소는 읽기만 했고 수정하지 않았다.


## 2026-11-18 화면 재설계
캡스톤 내부 복제본의 CSS와 화면 구성을 공공기관형 업무지원 포털로 재설계했다.
계정·품목·수량·예산·목적을 선택하는 화면, 현황·결재함·이력·상세 조회를 제공한다.
현재 CSS가 원본과 동일하다는 이전 설명은 더 이상 적용되지 않는다. 원본 저장소는 변경하지 않았다.


## 최종 범위 축소 (2026-11-18)
사용자 지시로 구매 신청·결재·반려 화면/API를 제거하고 기관 통합 로그인 화면으로 축소했다.
기존 사용자 데이터와 과거 구매 데이터·관제 증거는 삭제하지 않았다.
