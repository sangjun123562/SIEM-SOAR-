01. 로그인과 계정

선택한 계정의 소속 정보는 내 계정 메뉴에서 확인할 수 있습니다. 다른 계정으로 접속하려면 먼저 로그아웃하세요.

02. 접속 상태 확인

접속 상태 확인 버튼은 서버에 현재 세션의 유효성을 다시 묻습니다. 확인 시각은 응답을 받은 시점에 갱신됩니다.

03. 연결 오류가 나타날 때

네트워크가 제한되면 세션을 확인할 수 없습니다. 연결이 복구된 후 상태 확인을 다시 눌러주세요.

04. 안전하게 종료하기

우측 상단의 로그아웃을 누르면 현재 세션이 해제되고 로그인 화면으로 돌아갑니다.
