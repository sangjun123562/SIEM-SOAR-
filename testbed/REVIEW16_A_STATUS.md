## 실제 환경 읽기 전용 확인

별도 Docker inspect와 관제 DB SELECT로 확인했으며 변경 명령은 실행하지 않았다.
- A+B live CPU 1.79 / 1472MiB. 브라우저 tunnel 포함 CPU 1.85 / 1504MiB.
- Grafana CPU0.15 추가 시 실행 서비스 합계2.00. 일회용 경로 도우미0.07·action-probe0.05까지 동시에 실행하면 한도 초과 가능.
- 이전 문서의1.89/2.04는 CPU0.10 산술 오류로 정정. 기본 한도 초과가 확정됐다는 이전 설명을 철회한다. Grafana 미기동·미검증 사실은 그대로다.
- GW_BLOCK 잔여 규칙0. 실제 계정 권한은 위 #12 범위만 확인.
